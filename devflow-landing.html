11 Modules
Everything you need. Nothing you don't.
Every module is purpose-built for a specific part of the dev lifecycle. Colored dots indicate the phase each module belongs to.
📄

Documents

Full Markdown editor with AI-assisted editing, SVG and draw.io diagram embeds, PDF export, reusable templates, and one-click revert for every AI change. Write PRDs, RFCs, and ADRs that live inside your project.

🏗️

Project Layers

Define your deployment units — Frontend, Backend API, Mobile, Database. Each layer maps to a folder path and automatically wires into Git Changes, Issues, Test Runner, and Workflows.

🎨

UI Mockup Generator

Describe a screen in plain English — AI generates production-quality HTML/CSS instantly. 30+ templates across 8 categories. Live in-app preview. Bulk queue generation with your Style Guide enforced automatically.

🖌️

Style Guide

Project-wide design token editor for colors and typography. The single source of truth for your visual identity — feeds the Mockup Generator automatically so every screen stays on-brand.

⚡

Workflows

Build reusable multi-step AI pipelines — code review, feature implementation, documentation generation. Each step has its own prompt, inputs, and outputs. Drag-and-drop reorder, live streaming output, and success criteria tracking.

🔄

Prompt Queue + DevFlow Agent

Queue AI coding tasks for sequential execution. The agentic loop builds a repo map, generates a step-by-step plan you can review and edit, then executes — writing real files with real tool calls. No copy-pasting required.

💬

AI Console

Multi-turn project-aware chat that auto-loads your documents and open issues as context before every conversation. Streaming responses, token count estimate, full history. Ask anything about your codebase.

🐛

Issue Tracker

Lightweight per-project bug tracker with severity levels, status workflow (Open → In Progress → Resolved), and layer association. AI-assisted analysis suggests next steps. Batch process multiple issues with a queue.

🧪

Test Generator

AI reads your layer's setup instructions to detect the language and test framework — Flutter, Python/pytest, JavaScript/Jest, Go, Ruby/RSpec, C#/MSTest, and more. Generates appropriate test files without configuration.

▶️

Test Runner

Run your test command and stream live PTY output directly in-app. Auto-parses pass/fail/skip counts from 9+ frameworks. Full run history per layer with timestamps and duration — no external dashboard needed.

📦

Git Changes

Unified git view across every project layer — multiple repos on a single screen. See changed files, inline diffs, pending commit counts. Stage, unstage, and commit each layer without ever leaving DevFlow AI.

⚙️

Settings & Multi-Model Config

Add unlimited AI model configurations and assign a different model to each page. Encrypted local API key storage, SQLite database backup and restore, Telegram notifications for long-running agent jobs.

🤖 AI Backends

Bring any model. No vendor lock-in.

Connect any AI backend — cloud or fully local. Assign a different model to each module: Documents on Claude, Workflows on Ollama, Mockups on Gemini. Your API keys are encrypted and never leave your machine.

Anthropic Claude Google Gemini CLI OpenAI-compatible OpenRouter Groq LM Studio Together AI Aider CLI 🖥 Ollama (local) 🤖 DevFlow Agent

📖 Repo-aware context

Builds a file tree + function/class signature map of your codebase before every agentic task — no manual context needed.

🛠 Real tool calling

read_file, write_file, search_code, run_command — the agent takes real actions on real files in your project.

✅ Plan approval gate

Review and edit the agent's step-by-step plan before it executes anything. You stay in complete control.

🔍 Optional RAG

ChromaDB + sentence-transformers for semantic code search across large codebases. Gracefully skipped if not installed.
